# 08 — Changes to the existing public frontend (`frontend/`)

Keep vanilla JS, the existing files, components and visual design. Every new page uses the same
`<head>` (fonts, `main.css`), `data-header` / `data-footer` mounts and `ui.js` helpers.

## 1. Theme & config bootstrap

1. Add `<link rel="stylesheet" href="/theme.css">` **after** `main.css` in every HTML page.
   `/theme.css` is generated by the backend (docs/07 §10.1) and only overrides CSS variables + fonts.
2. Refactor `main.css` so every brand colour comes from variables (no visual change with defaults):
   replace hard-coded `#0F4C3A`, `#0A2F25`, `#176149`, `#1E6B53`, `#C9A86C`, `#85652F`, `#FAF7F2`,
   `rgba(15, 76, 58, …)`, `rgba(10, 47, 37, …)` and the inline SVG data-URI stroke colour with
   `var(--green)`, `var(--green-900)`, `var(--green-2)`, `var(--gold)`, `var(--gold-ink)`, `var(--bg)`,
   `color-mix(in srgb, var(--green) N%, transparent)`. The generator maps:
   primary→`--green`, primaryDark→`--green-900`, derived lighter→`--green-2`, tint→`--green-50`,
   accent→`--gold`, accentInk→`--gold-ink`, tint→`--gold-50`, background→`--bg`, surface→`--surface`,
   ink→`--ink`, muted→`--muted`, fonts→`--f-display`/`--f-body`, radius→`--r`/`--r-lg`.
3. `config.js`: `dataSource: 'api'`, `apiBase: '/api/v1'`, `nearby.source: 'api'`. Keep the mock path
   for local development only (`?mock=1` or `localStorage.mz_mock=1`). Do not load
   `data/properties.js` when `dataSource === 'api'`.
4. New `MZ.boot()` in `ui.js`: fetches `/public/config` (cache in `sessionStorage` 5 min), merges into
   `MZ.config` (brand, contact, licensing, map, features), then pages run. Every page script becomes
   `MZ.boot().then(function () { … existing code … })`. On failure fall back to the static config.
5. Logo in header/footer/drawer uses `config.brand.logoUrl` / `logoLightUrl` when set (fallback to the
   current inline SVG mark + name).

## 2. URLs

- Property links: use `p.url` (`/property/1001-<slug>`) from the API. `property.js` reads the id from
  `location.pathname` (`/property/(\d+)`), then hash `#p-1001`, then `?id=` — all three keep working.
- Landing pages `/properties/{city}/{type?}/{offer?}`: the API serves `properties.html` with
  `<script>window.__PRESET__ = {...filters, h1, introHtml, faqs}</script>`; `listing.js` applies
  `__PRESET__` before `takeHandoff()`, shows the H1/intro above the results and the FAQ block below.
- `favorites.html` stays; add `/account/*` pages (§5).

## 3. Header (logged-in state)

- Logged out: add «دخول» ghost button (opens OTP login modal) before «اعرض عقارك».
- Logged in: notification bell (unread badge, dropdown of last 8, «عرض الكل») + avatar menu:
  «حسابي», «حجوزاتي», «معايناتي», «المفضلة», «الإشعارات», «الإعدادات», «تسجيل الخروج».
- Mobile drawer gets the same items.
- Favorites: when logged in, `ui.fav` uses `/me/favorites` (optimistic) and merges localStorage once
  on login.

### OTP login modal (component in `ui.js`)
Step 1: «البريد الإلكتروني» (and «رقم الجوال» tab if SMS enabled) → «إرسال الرمز».
Step 2: 6-digit code input (auto-advance, paste support, resend timer 60 s) → for new users: name,
mobile, PDPL consent checkbox «أوافق على سياسة الخصوصية ومعالجة بياناتي». Uses existing modal styles.

5. **Live status**: subscribe to `property:{id}`; on `property.updated` re-render badges/pricebox and

## 9. Real-time client

Serve the Socket.IO client from the API (`/ws/socket.io.js`) and load it lazily in `ui.js`
(`MZ.rt.connect()`), reconnect with backoff, re-subscribe rooms after reconnect, pass the customer
access token when logged in.

## 10. Consent & analytics

Cookie consent bar (Arabic) with «قبول الكل / الضرورية فقط / تخصيص». Analytics/pixels from
`settings.seo` load only after consent. Store choice in a first-party cookie for 12 months.

## 11. Content placeholders to wire

`about.html` placeholders → `GET /public/pages/about`; footer social links, contact page info and office
map → `/public/config.contact`; privacy/terms pages (`privacy.html`, `terms.html`) new, simple
article layout.

Copy `spec-assets/rega-logo.png` → `frontend/assets/img/brands/rega.png` and `spec-assets/ejar-logo.png` →
`frontend/assets/img/brands/ejar.png`. The provided files are small (≈160×57 px): render them at
≤ 36 px height, and replace them with official high-resolution/SVG versions when the company supplies
them (keep the same file names). Add payment-method logos (mada, Visa, Mastercard, Apple Pay,
STC Pay) as SVGs from the providers' official brand kits only.
