# الأمان والخصوصية (PDPL) — قائمة المراجعة قبل الإطلاق

مرجع: `docs/10 §1–§2`, `docs/03`, `docs/05 §6`, `docs/12`.

## 1. المصادقة والجلسات
- [x] كلمات المرور Argon2id (memoryCost 19456, timeCost 2).
- [x] JWT وصول 15 دقيقة + تحديث دوّار (كوكي httpOnly `nx_rt`) مع كشف إعادة الاستخدام (إبطال العائلة).
- [x] 2FA (TOTP) للسوبر-أدمن والموظفين؛ إلزام للأدوار owner/admin/finance عبر `mustSetup2fa`.
- [x] OTP العملاء (6 أرقام، 10 دقائق، 5 محاولات).
- [ ] قفل بعد 10 محاولات فاشلة 15 دقيقة (تحديد المعدّل على Redis — يُفعَّل مع Redis).

## 2. التفويض والعزل (multi-tenant)
- [x] RBAC: `PermissionsGuard` + صلاحيات دقيقة؛ قيود الصفوف (AccessScope) للوكيل.
- [x] عزل المشتركين: `tenantId` + امتداد Prisma يحقن/يفلتر تلقائياً؛ تحقّق نطاق التكاملات.
- [x] فصل الاستحقاقات (Entitlements) عن الصلاحيات (docs/13).
- [ ] RLS على مستوى القاعدة (دفاع بالعمق) — `infra/sql/rls.sql` بعد توصيل `SET LOCAL app.tenant_id`.

## 3. الأسرار والبيانات
- [x] أسرار التكاملات مشفّرة AES-256-GCM (`APP_ENCRYPTION_KEY`)، لا تُعاد (قناع ••••1234)، محجوبة في السجلّات (docs/05 §6).
- [x] المال بالهللات (BigInt)؛ الخادم هو المرجع للأسعار والحالات (إعادة الجلب من المزوّد قبل وسم الدفع).
- [x] الهوية الوطنية لا تُخزَّن خاماً (SHA-256 + pepper، آخر 4 أرقام فقط).
- [ ] رؤوس الأمان: helmet مُفعّل؛ أضِف CSP الكاملة وHSTS عبر Caddy/Traefik (docs/10 §1).

## 4. المدفوعات
- [x] كل اتصال خارجي عبر `IntegrationsGateway` (قاطع دائرة + سجل).
- [x] تأكيد الدفع يتحقّق من الحالة/المبلغ/العملة ويُعلَّم مرّة (idempotent، قفل صف)؛ عدم التطابق → `payment.anomaly`.
- [x] webhook يتحقّق من التوقيع ويُخزَّن في `WebhookEvent` (idempotent عبر provider+externalId).
- [x] بيانات البطاقة لا تمرّ بخادمنا (Moyasar hosted/embedded).

## 5. PDPL (نظام حماية البيانات الشخصية)
- [x] موافقة صريحة عند التسجيل (`consentAt`)، وفصل موافقة التسويق.
- [x] حذف الحساب (`DELETE /me`) → إخفاء الهوية بعد 30 يوماً ما لم توجد حجوزات مفتوحة.
- [x] تصدير البيانات (`GET /me/export`).
- [x] سجلّ تدقيق لكل تغيّر حالة (`AuditLog`، الأسرار محجوبة).
- [ ] تحليلات/بكسلات بعد الموافقة فقط (شريط الموافقة — واجهة).
- [ ] تفضيل استضافة داخل السعودية عند الإمكان (docs/10 §2).

- [ ] اختبار استعادة نسخة موثّق (docs/10 §4).
