# منزلة العقارية — الواجهة الأمامية

موقع خاص بمنشأة عقارية واحدة (ليس منصة متعددة البائعين) — موقع ثابت (HTML / CSS / JavaScript بدون أدوات بناء) جاهز للرفع على أي استضافة.

## التشغيل

- **على السيرفر (Coolify):** المستودع فيه `Dockerfile` يشغّل الموقع على Nginx (المنفذ 80) بإعدادات `deploy/nginx.conf`. في Coolify اختر Build Pack: Dockerfile.
- **محلياً:** `npx serve .` ثم افتح `http://localhost:3000` (يدعم الروابط بدون `.html`).

الروابط نظيفة بدون `.html`: `/about`، `/properties`، `/property#p-1001`. الروابط القديمة المنتهية بـ `.html` تُحوَّل تلقائياً للشكل الجديد.
عند الرفع على استضافة أخرى غير Nginx المرفق يجب إعداد الروابط النظيفة فيها (مثلاً `.htaccess` على Apache).

## الصفحات

| الملف | المحتوى |
|---|---|
| `index.html` | الرئيسية: بحث، أنواع العقار، المميز، الفرص الاستثمارية، الخريطة، المدن، الخدمات |
| `properties.html` | قائمة العقارات: فلاتر ذكية حسب النوع والعرض، ترتيب، عرض شبكة / قائمة / خريطة |
| `property.html#p-1001` | تفاصيل العقار: معرض صور، مواصفات حسب النوع، مزايا، بيانات استثمارية، خريطة وخدمات قريبة، الترخيص، حاسبة تمويل، حجز معاينة |
| `about.html` | من نحن |
| `contact.html` | نموذج طلب (شراء، إيجار، عرض عقار، استثمار، إدارة أملاك) |
| `favorites.html` | المفضلة (محفوظة في المتصفح) |
| `404.html` | صفحة الخطأ |

روابط العقار تقبل الشكلين: `/property#p-1001` و `/property?id=1001`.
صفحة العقارات تقبل الفلاتر في الرابط أيضاً، مثل: `/properties?offer=rent&city=riyadh&types=apartment,villa`.

## البنية

```
assets/
  css/main.css          نظام التصميم والمكونات
  js/config.js          الإعدادات: الهوية، التواصل، مصدر البيانات، مزوّد الخرائط
  js/schema.js          نموذج البيانات: الأنواع، العروض، الحالات، الحقول حسب النوع
  js/api.js             طبقة البيانات (تجريبية أو API)
  js/map.js             طبقة الخرائط (OpenStreetMap / Google)
  js/ui.js              المكونات المشتركة: الهيدر، الفوتر، البطاقة، المفضلة…
  js/pages/*.js         منطق كل صفحة
  img/photos/           صور تجريبية (Unsplash)
  img/props/            مخططات توضيحية للأدوار
data/properties.js      بيانات تجريبية (تُستبدل بالـ API)
API.md                  عقد الـ API المطلوب من الباك إند
```

## قبل الإطلاق

- [ ] الاسم والشعار والهوية: `config.js` → `brand`، وشعار SVG داخل `ui.js` → `logo()`، و`assets/img/favicon.svg`
- [ ] أرقام التواصل والبريد والعنوان: `config.js` → `contact`
- [ ] رخصة فال والسجل التجاري: `config.js` → `brand`، وصفحة `about.html`
- [ ] إحداثيات المكتب: `assets/js/pages/contact.js`
- [ ] الصور الحقيقية للعقارات بدل الصور التجريبية في `assets/img/photos/` (المصادر في `CREDITS.md`)
